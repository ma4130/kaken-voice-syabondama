# 声で飛ばす！しゃぼん玉の旅

声を出すとしゃぼん玉が上昇し、声を止めるとゆっくり下降。雲や木を避けてゴールを目指すゲームです。

- **こども**：大きなすきまで、ゆったり遊べる（ぶつかっても何回でもやり直せる）
- **おとな**：せまいすきまと動く雲に挑戦（しゃぼん玉は3つ）
- 声を出す・止めるだけで操作できる（マイクがないときは画面長押し／スペースキー）

## あそびかた

`index.html` 1枚だけで動きます（ビルド不要）。
マイクを使うには https か localhost で開いてください（GitHub Pages ならそのまま使えます）。

- 「かんど」で声への反応しやすさを調整できます
- 開始時に1秒ほど周りの音をはかって、雑音に反応しにくくしています
